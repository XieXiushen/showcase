自检脚本下载区（H2）

《本机部署自检脚本》

文件清单：自检.cmd、verify_vision.py、说明.md（脚本包，3 个文件）

一段命令跑完三段判据：

  1. 启动目录检查——llama-server.exe 同级目录里有没有 ggml-cuda.dll / cublas64_13.dll（我们的实测坑：这两个 DLL 只在子目录 cuda_v13\ 下，直接双击会静默退化成 CPU）；
  2. 显存与占卡进程清单——nvidia-smi 当前 used 与占用进程，对照本机桌面常驻约 1331 MiB 的基线；
  3. 驻留显存是否落在预期区间——加载后整卡占用若只有 1.3 GB 级，打印「可能已退化 CPU」。

这三段判据对应的实测事实：正确 CUDA 启动时整卡占用约 8.3 GB、decode 117.33 tok/s；退化时 GPU 恒 1329–1342 MiB、decode 12.70 tok/s（慢 9.2 倍），而进程与 /health 都正常、日志里没有报错。「能跑」不等于「在 GPU 上跑」。

脚本以 Windows + llama-server（本机为 D:\ollama\bin\llama-server.exe，端口 8081）为前提，其他环境请按注释改路径。
