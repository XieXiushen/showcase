# showcase（对外展示站）

纯静态单页站点，无构建步骤、无依赖：站点根目录的 `index.html` 即首页。

内容对应三条主线（自动驾驶地图制作与使用 / 云端架构 / AI 基础设施）与两条产品线（地图变更检测 / 私有化运维）。

## 当前状态

- 页面中的「GitHub 仓库链接」「邮箱 / 微信」为占位文本，待确认后替换。
- 托管：GitHub Pages（分支 `main`，路径 `/`）。
- 可迁移到任意静态托管，页面不依赖任何后端或常开主机。

## 修改

直接编辑 `index.html`（样式内联），提交推送后自动重建。

部署与迁移步骤见 `DEPLOY.md`。
